## What the maintainers do

The maintainers review and merge pull requests, triage issues, handle security
reports sent to `security@certping.com` (see [SECURITY.md](SECURITY.md)) and cut
releases (see [.github/RELEASING.md](.github/RELEASING.md)). The lead maintainer
makes the final call on architecture, security and releases.
`.github/CODEOWNERS` requests reviews from the CertPing core team
(`@certping-labs/certping`), and a pull request needs an approval from a
maintainer other than its author.

Please send security reports to `security@certping.com`, not to a
maintainer's own address, and use GitHub issues and pull requests for
everything else.

## Becoming a maintainer

Anyone can contribute: see [CONTRIBUTING.md](CONTRIBUTING.md). Sustained,
high-quality contributions and reviews over several months, and agreement from
the existing maintainers, lead to maintainer status. New maintainers are added
to this file and to `.github/CODEOWNERS` in the same pull request.
